# React 3D Portfolio

A 3D portfolio website built with React, TypeScript, Vite, and Three.js. The experience presents a Windows 95-inspired desktop environment with interactive 3D scenes, animated camera movement, and a mobile-friendly fallback experience.

## Features

- Interactive 3D portfolio scene rendered with React Three Fiber
- Windows 95 aesthetic
- Animated loading experience and camera controls
- Built with TypeScript for a more maintainable frontend setup

## Tech Stack

- React 19
- TypeScript
- Vite
- Three.js
- @react-three/fiber
- @react-three/drei
- GSAP
- HTML2Canvas

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the local Vite URL shown in the terminal.

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — build the project for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint checks

## Project Structure

- `src/` — main application source code
- `src/models/` — 3D scene models and components
- `src/OS/` — Desktop interface
- `public/` — static assets and textures

## Notes

This project is still evolving, but it already provides a polished interactive portfolio experience for desktop browsers.
